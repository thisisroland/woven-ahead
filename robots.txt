# Roland Ananda — private personal portfolio.
# Shared by direct link only. Not meant to be found through search.
#
# The CV PDF cannot carry a noindex tag, so it is blocked by path in every
# group below; nothing on the open web links to it.
#
# Every page carries <meta name="robots" content="noindex, nofollow, ...">.
# That is the rule that actually keeps the site out of search results, and a
# crawler has to be allowed to fetch the page in order to read it. So ordinary
# search crawlers are let in here on purpose; they read the noindex and drop
# the site. Blocking them outright would leave them unable to read the rule,
# and a bare URL could still be listed if someone links to it.

# PDF and Markdown files cannot carry a noindex tag of their own, so they are
# blocked by path in each search engine's group below.
